# Warehouse - Система управления складом (Backend)

## О проекте
Backend часть дипломной работы - система управления складом.

## Технологии
- Laravel 10
- PHP 8.1
- MySQL
- REST API

## Установка
1. `composer install`
2. Скопируйте `.env.example` в `.env` и настройте БД
3. `php artisan migrate`
4. `php artisan serve`
